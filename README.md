# <p align="center">cyberpunk-giveaway-landing</p>
Landing page on the theme of the game "Cyberpunk 2077" for participating in the giveaway of a game console. Built using HTML, CSS, Sass, JavaScript, Swiper, Vite.

## Setup and Install

1. Go to the folder where you want to store the project.

2. Clone the repository:
```bash
git clone https://github.com/Tanya57790/cyberpunk-giveaway-landing.git
```

3. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

## Getting Started

First, run the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Run the build:
```bash
npm run build
# or
yarn build
# or
pnpm build
# or
bun build
```

Run the production server:
```bash
npm run preview
# or
yarn preview
# or
pnpm preview
# or
bun preview
```
